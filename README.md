# stmut-hires

upgrade stmut to handle high resolution spatial transcriptomics data (VisiumHD, StereoSeq)

## stmut-HD (Development version)

⚠️ This project is under active development.  
It is the next-generation version of [stmut](https://github.com/limin321/stmut),  
optimized for high-resolution spatial transcriptomics (VisiumHD, Stereo-seq).  

The core functionality is being actively tested. Please check back for updates.
